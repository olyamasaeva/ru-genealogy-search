# Рецепты по источникам

## Установка и запуск

Проверено на Linux (bash), Node 20, playwright 1.63, Python 3.12.

```bash
S=~/.claude/skills/ru-genealogy-search/scripts
export NODE_PATH=~/.cache/genealogy-node/node_modules
node -e "require('playwright')" 2>/dev/null || (mkdir -p ~/.cache/genealogy-node && cd ~/.cache/genealogy-node && npm i playwright@1.63 && npx playwright install --with-deps chromium)
node -e "require('playwright').chromium.launch().then(b => b.close()).then(() => console.log('chromium ok'))"
```

Дальше все команды — с полным путём `$S/…`, из любой папки; путь к `.ged` бери
в кавычки. Делай паузу 2–4 секунды между запросами и один прогон за раз.

**Сеть** (наблюдение на 2026-10, с VPN-прокси): notariat, ОБД, visz отвечали
через прокси; база эвакуации — только напрямую (`--direct`). У тебя может
быть иначе. Браузерным скриптам прокси задаётся `PW_PROXY=socks5://host:port`.

## Сначала — территория и время

Перед выбором источника определи: где произошло событие (по
административному делению **того** времени: губерния, уезд, волость,
приход), год, конфессию и язык записи. Отсюда — нужный архив и каталог. Номера
каталогов и фондов в этом файле — примеры по Олонецкой губернии, на другие
регионы их не переносить: найди свой в каталоге FamilySearch, на сайте
регионального архива или в справочнике «Метрические книги в архивах России»
(metrics.tilda.ws).

**Регексы мест** для фильтра реестра (проверяются только адрес и округ, не
ФИО). Примеры — для своего региона составь аналогичный из районов и городов;
без готового списка запускай без фильтра:
- Карелия: `'карел|петрозавод|прионеж|кондопож|олонец|пряж|медвежьегор|сегеж|беломор|кем[ьи]|пудож|суоярв|сортавал|питкярант|лахденпох|лоух|калевал|костомукш|муезер'`
- Вологодская: `'вологод|кириллов|белозер|вытегор|череповец|кадуй|бабаев|шексн|сокол|тотьм|устюг|грязовец|харовск|вожег|сямж'`
- Ленинградская и СПб: `'ленинград|санкт|петербург|всеволож|лодейнопол|подпорож|волхов|тихвин|кировск|гатчин|выборг'`

## Реестр наследственных дел (notariat.ru)

- `node "$S/notariat.js" '["Фамилия Имя Отчество", …]' 'регекс-мест'`
- Перебор отчеств: `node "$S/notariat.js" "$(python3 "$S/names.py" --surname Смирнова --name Мария)" '<регекс мест>'`.
  Словарь ~90 имён отцов (с XIX века: Антип, Евсей, Трофим, Савва…), варианты
  ё/е и старые формы («Геннадиевна»). Несклоняемая фамилия — укажи
  `--female`/`--male`. Карельские, финские, вепсские отцы —
  `--extra-fathers` или готовые отчества `--patronymics-file`.
- Скрипт останавливается на 403 или капче, на 429 ждёт `Retry-After`, в конце
  печатает, сколько записей отсеял фильтр мест.
- Внутри: страница `https://notariat.ru/ru-ru/help/probate-cases/`. Из её
  контекста идёт `POST /api/probate-cases` с JSON
  `{name, birth_date:'NULL', death_date:'NULL'}` и заголовком `x-csrftoken`
  из куки. Капчи нет.
- Один запрос возвращает все дела на это ФИО сразу, без страниц (на частое
  ФИО — сотни строк).
- Ответ: ФИО, дата рождения (YYYYMMDD), дата смерти, последний адрес,
  нотариальный округ, палата, номер дела. Есть дела с 1969 года, по 1990-м и
  позже полнота хорошая.
- Только точное полное ФИО. Ищи и под фамилиями из других браков.
- Наследников и состав наследства реестр не показывает. Копию дела у
  нотариуса может получить наследник.

## Эвакуированные из Ленинграда (ЦГА СПб)

- `python3 "$S/evacuation.py" [--direct] [--max-pages N] "Фамилия Имя Отчество" …`
- `https://evacuation.spbarchives.ru/table?fio=…&pageNumber=N&recordsPerPage=25`.
  Строки: `<tr class="clickable-row" data-href="./card?cardRecordId=…">`.
  Карточка: `/card?cardRecordId=…`.
- Через VPN часто не отвечает — тогда `--direct` (без прокси окружения).
- Ищет по подстроке: «Мария Ивановна» без фамилии тоже работает, но даёт
  сотни страниц; по умолчанию 20 страниц, при обрезке печатает `truncated`.
- В базе в основном городские эвакуированные. Депортированных финнов из
  пригородов (март 1942) ищи в «Возвращённых именах» по полю «финн».

## «Возвращённые имена» (РНБ, visz.nlr.ru)

- `node "$S/visz.js" lname Фамилия …` или `node "$S/visz.js" memo "1903 финн" …`
- В форме `#lname` (начало фамилии) и `#memo` (любые слова справки: год,
  деревня, национальность, предприятие). Заполняй одно поле: два сразу дают 0.
- Книги: Ленинградский мартиролог, книги памяти Карелии, Мурманской,
  Вологодской, Архангельской, Новгородской и других областей,
  «Спецпоселенцы в Карелии». Раскулаченных без суда там почти нет.

## ОБД «Мемориал»

- `node "$S/obd.js" '[["Фамилия","Имя","Отчество"]]' 'регекс'` — печатает статус
  `complete` / `truncated` / `parse_error`.
- `https://obd-memorial.ru/html/search.htm?f=&n=&s=`; строки — `.search-result`;
  карточка — `info.htm?id=…`. Скрипт берёт первую страницу — 20 строк. Для
  частой фамилии сужай запрос именем и отчеством. Расширенный поиск с
  `fulltext` возвращает 0, не трать на него время.
- В донесениях военкоматов бывает «жена/мать … деревня» — это адрес семьи в
  1940-х.

## «Память народа»

Капча и поведенческая проверка (`/api/v1/captcha/gen`). Не обходить: ищет
пользователь сам (награды выживших, учётные карточки), формат результата —
как в handoff-familysearch.md.

## FamilySearch

Защита от ботов (Incapsula): curl и headless получают «request blocked».
Каталог, плёнки (DGS) и индексы смотрит пользователь сам или его браузерный
Клод, если правила сайта это допускают: инструкция и шаблон задания —
[handoff-familysearch.md](handoff-familysearch.md). Куки не брать.

Каталоги ищутся по месту в старом делении: «<страна>, <губерния>, <уезд>,
<приход>». Какие годы сохранились, часто показывает справочная система
регионального архива (пример — «Метрические книги» Национального архива
Республики Карелия, http://rkna.ru/projects/metrics/). Для каждой губернии
архив и каталог находи заново.

## ВКонтакте

- Страница строится скриптом: WebFetch и defuddle получают пустой каркас.
  Открывай headless playwright, `https://vk.ru/id<N>`, жди ~20 секунд, бери
  `document.body.innerText`.
- Без входа видны имя, город, место работы и стена (часто одни перепосты).
  Друзья, альбомы и фото закрыты входом: гостю ВК пишет «пользователь пока не
  добавил друзей».
- Поиск людей ВК (vk.com/search/people) и Одноклассников работает только
  после входа. Искать в нём будет пользователь; ты даёшь запросы: фамилия в
  мужской и женской форме, девичья фамилия в скобках («Иванова (Петрова)» —
  так часто подписывают профили), город или район, примерный возраст.
  Хорошие следы — друзья уже известного родственника с той же фамилией,
  группы родной деревни, школы, землячества.
- Под аккаунтом пользователя не входить. Друзей, фото и выдачу поиска
  пользователь смотрит сам, тебе присылает скриншоты или имена.
- Ценно в подписях и комментариях: «наши родители …» (отчества и девичьи
  фамилии), «помяним» (факт смерти), «баба Маша» (поколение), друзья с той же
  фамилией. Записывай как гипотезы QUAY 0–1, живых — с `RESN privacy`.

## Яндекс «Поиск по архивам»

- `https://yandex.ru/archive/search?text=…`; данные — в `__NEXT_DATA__`
  страницы; каталог — `/archive/api/catalog/<uuid>`.
- После ~40 запросов включается капча, тогда остановись.
- Покрытие неравномерное: проверь, есть ли там нужный архив. Например,
  Национального архива Республики Карелия там нет.

## Не проверено скриптом

«Блокада. Книга памяти» (РНБ, тот же сайт visz.nlr.ru, раздел «Блокада»),
лютеранские метрики Ингерманландии (ЦГИА СПб, финские архивы, HisKi). Нужны
для финнов и для детей, умерших в эвакуации. Перед использованием проверь
адрес и форму.

## «Открытый список»

MediaWiki: `https://openlist.wiki/index.php?search=Фамилия&fulltext=1&limit=100`.

## Geneteka (польские и белорусские католики)

`https://geneteka.genealodzy.pl/api/getAct.php?draw=1&start=0&length=200&op=gt&lang=pol&bdm=B&w=<код региона>&rid=B&search_lastname=…&search_name=&from_date=&to_date=`.
`bdm` и `rid` — одно значение: B (рождения), S (браки) или D (смерти); `w` —
код региона (пример: `10pl` — Подляское воеводство; список — в форме поиска
на сайте); `start` — сдвиг страницы по 200. Покрытие приходов проверь на
сайте до вывода «не найдено». Фамилию пиши латиницей, в польском написании.

## Мосты через 1920–1960

В России актовые записи ЗАГС 100 лет хранятся в органах ЗАГС и выдаются
только по запросу родственника; открытых онлайн-баз за эти годы нет. В других
странах бывшего СССР порядок свой — проверь у хранителя. Поэтому связи этих
лет собирай косвенно:
- **реестр нотариата**: даты рождения 1900–1930-х у тех, кто умер после
  1990 года, и их адреса;
- **донесения ОБД**: адрес семьи и имена жён и матерей;
- **отчества**: отчество ребёнка — это имя отца. Перебирай кандидатов по
  нему;
- **подписи к фото и комментарии в ВК**, которые приносит пользователь;
- **похозяйственные книги** сельсоветов: районный архив, только запросом;
- **«Списки населённых мест»** и исторические описания приходов (sobory.ru,
  Википедия: `index.php?title=…&action=raw` с `--data-urlencode`) — чтобы
  найти приход и деревню, по которым потом искать метрики.
